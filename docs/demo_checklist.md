# 시연 체크리스트 (MindRium 상담 챗봇 데모)

기준: 태그 `chatbot-handover-2026-10-04` (상담 응답은 `respond-v11-demo-freeze`와 같음). 시연 전에는 상담 로직과 프롬프트를 바꾸지 않습니다.
구조 설명은 [`counseling/chatbot_system.md`](counseling/chatbot_system.md)에 있습니다.

## 0. 준비물 (하루 전)

- [ ] 개발용 Mac, 안드로이드 기기, 같은 Wi-Fi(무선 디버깅) 또는 USB 케이블
- [ ] `backend/app/.env`에 OpenAI 키 (`OPENAI_API_KEY`) — 값은 문서에 적지 않는다
- [ ] 데모 계정 비밀번호 (따로 전달받은 값)
- [ ] MongoDB 실행 중 (`mongodb://127.0.0.1:27017`)
- [ ] 데모 계정 데이터 초기화 (지난 리허설의 대화를 지우고 합성 기록으로 되돌림):
  ```bash
  cd backend/app
  MONGO_URI=mongodb://127.0.0.1:27017 DB_NAME=mindrium_dogfood \
    DEMO_PASSWORD='<데모 비밀번호>' python3 ../scripts/seed_demo_account.py
  ```

## 1. 백엔드 실행

```bash
cd backend/app
MONGO_URI=mongodb://127.0.0.1:27017 DB_NAME=mindrium_dogfood PYTHONPATH=. \
  python3 -m uvicorn main:app --host 0.0.0.0 --port 8090
```

코드를 바꾼 뒤에는 반드시 재시작합니다(프롬프트는 시작할 때 읽힘).

## 2. 사전 점검 + 데모 빌드 설치

```bash
DEMO_PASSWORD='<데모 비밀번호>' tools/demo/preflight.sh --install
```

모두 `OK`여야 합니다. 점검 항목: 백엔드 응답, 데모 계정 로그인, 5주차, 과거 상담 기록,
상담 모델 응답(`respond_v11`, OpenAI 키), 기기 연결, 포트 포워딩, B 경로 빌드 설치.
무선 디버깅이 끊겼다 다시 붙으면 `preflight.sh`를 다시 실행합니다(포워딩을 다시 건다).

## 3. 기기 로그인

- [ ] 앱 실행 → 데모 계정(`mindrium.demo@example.com`)으로 로그인
- [ ] 홈 상단에 "데모 사용자님", 5주차 화면인지 확인

## 4. 앱 내 확인 (시연 직전, 각 1턴)

새 세션에서 아래를 짧게 확인한 뒤, 데모 계정을 1단계 초기화 명령으로 되돌리고 앱에서 새로고침(↻)합니다.

- [ ] 일반 상담: "다음 주 발표 때문에 걱정돼요" → 걱정을 받아 주고 질문 하나
- [ ] 앱 질문: "걱정 일기는 어디서 봐요?" → 실제 메뉴로 안내
- [ ] 과거 기록: "나 예전에도 발표로 걱정한 적이 있었던 것 같아" → 지난 발표 상담의 걱정과 그때 정리한 생각('긴장해도 준비한 내용은 설명할 수 있고…')을 직접 말함
- [ ] 종료: "오늘은 여기까지만 할래요" → 바로 마무리
- [ ] (선택) B 실패 시 A 대체 확인: 백엔드를 잠깐 끄고 한 턴 → 결정론 답이 나오는지. 확인 후 다시 켠다

## 5. 시연 대본 (한 세션)

| 순서 | 사용자 | 보여 주는 것 |
|---|---|---|
| 1 | "다음 주 발표 때문에 걱정돼." | 자연스러운 상담 시작 |
| 2 | (상담자 질문에 1~2턴 답하기) "말이 막히면 다들 비웃을 것 같아." | 맥락을 따라가는 대화 |
| 3 | "예전에 나도 비슷한 걱정 한 적 있었나?" | DB 기반 개인화(과거 상담 회상) |
| 4 | "그때 적은 걱정일기는 앱에서 어디서 볼 수 있어?" | 상담 → 앱 안내 전환 |
| 5 | "그럼 지금 걱정으로 다시 얘기해보자." | 상담 복귀 |
| 6 | (기법 질문에 답하기) | 현재 주차까지 승인된 기법 진행 |
| 7 | "자동사고가 뭐야?" | 승인된 용어 정의 |
| 8 | "오늘은 여기까지만 할래." | 자연스러운 종료 |

참고:
- "탈파국화" 같은 코퍼스 밖 용어는 정의하지 않는 것이 정상 동작입니다("정확히 정의해서 설명하기는 어려워요").
- 응답은 매번 조금씩 다르게 나옵니다(LLM). 대본은 흐름을 보여 주는 용도이고 문장을 고정하지 않습니다.

## 6. 위기 응답은 메인 시연에 넣지 않는다

질문을 받으면 "위기 표현은 LLM보다 먼저 SafetyGate가 처리하고 고정된 안내(109, 119)를 냅니다"라고 설명합니다.
보여 줘야 한다면 별도로 짧게 보여 주고, 키워드 기반 감지와 전문가 검수 전 문구라는 한계를 함께 말합니다.

## 7. 말하지 말아야 할 것

- 임상적으로 검증된 치료 도구라고 소개하지 않는다(1~3주차 기법 미승인, 위기 문구 미검수).
- 실제 사용자 기록이라고 하지 않는다. 데모 계정의 과거 기록은 합성 데이터다.

## 8. 문제가 생기면

| 증상 | 조치 |
|---|---|
| 답이 기계적이고 매번 불안 점수를 묻는다 | B 경로가 꺼짐: 데모 계정이 아니거나 빌드 플래그 누락 → `preflight.sh --install` |
| 응답이 오지 않거나 로그인 실패 | 포워딩 끊김 또는 백엔드 꺼짐 → `preflight.sh` |
| "Invalid or expired access token" | 앱에서 로그아웃 후 다시 로그인 |
| 과거 기록을 회상하지 않는다 | 데모 데이터가 지워짐 → 0단계 초기화 명령, 앱 새로고침 |
